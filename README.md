# UniReserve | سامانه مدیریت و رزرو امکانات دانشگاه

**UniReserve** یک پروژه آموزشی برای درس برنامه‌نویسی مبتنی بر وب است. هدف آن طراحی و پیاده‌سازی سامانه‌ای تحت وب برای مشاهده، رزرو و مدیریت امکانات و تجهیزات مشترک دانشگاه است.

## هدف پروژه

این سامانه با هدف کاهش فرایندهای دستی رزرو، جلوگیری از تداخل درخواست‌ها و بهبود مدیریت منابع دانشگاه طراحی می‌شود. کاربران می‌توانند امکانات موجود را مشاهده و برای استفاده از آن‌ها درخواست رزرو ثبت کنند؛ مسئولان نیز درخواست‌ها و منابع را مدیریت می‌کنند.

## ذی‌نفعان

- **دانشجویان:** جست‌وجوی منابع، ثبت رزرو و پیگیری وضعیت درخواست‌ها
- **استادان:** رزرو فضاها و تجهیزات موردنیاز برای فعالیت‌های آموزشی
- **مسئولان دانشگاه:** بررسی درخواست‌ها، مدیریت تجهیزات و رسیدگی به خرابی‌ها
- **مدیر سامانه:** مدیریت کاربران، منابع و گزارش‌های آماری

## امکانات برنامه‌ریزی‌شده

### امکانات اصلی
- ثبت‌نام و ورود کاربران
- نقش‌ها و سطح دسترسی برای کاربران مختلف
- نمایش و دسته‌بندی منابع دانشگاه
- جست‌وجو و فیلتر منابع بر اساس نوع و ظرفیت
- ثبت درخواست رزرو با تاریخ و ساعت شروع و پایان
- جلوگیری از رزرو هم‌زمان یک منبع
- تأیید، رد و لغو درخواست رزرو
- نمایش وضعیت و تاریخچه رزروهای کاربر
- مدیریت منابع و درخواست‌ها از پنل مدیر
- رابط کاربری واکنش‌گرا برای موبایل و رایانه

### امکانات تکمیلی پیشنهادی
- ثبت و پیگیری گزارش خرابی تجهیزات
- ثبت تحویل و بازگشت تجهیزات امانی
- اعلان داخل سامانه برای تغییر وضعیت درخواست
- ثبت نظر و امتیاز برای منابع
- داشبورد آماری و نمودار میزان استفاده از امکانات

## فناوری‌های مورد استفاده

- **Backend:** Python و Django (در مراحل بعدی توسعه)
- **Frontend:** HTML، CSS و JavaScript
- **UI Library:** MDUI 2 از طریق CDN
- **Database:** SQLite برای محیط توسعه اولیه
- **Charts (برنامه‌ریزی‌شده):** Chart.js

## وضعیت فعلی پروژه

در نسخه اولیه مخزن، دو صفحه رابط کاربری به‌صورت HTML آماده شده‌اند:

- `reservation.html` — فرم درخواست رزرو امکانات دانشگاه
- `signup.html` — فرم ثبت‌نام کاربران

این صفحات از کتابخانه MDUI نسخه ۲ از طریق CDN استفاده می‌کنند. در حال حاضر، فرم‌ها نمونه رابط کاربری هستند و هنوز به بک‌اند Django یا پایگاه داده متصل نشده‌اند.

## اجرای صفحات فعلی

۱. فایل‌های مخزن را دریافت کنید.
۲. اتصال اینترنت را فعال نگه دارید تا فایل‌های MDUI از CDN بارگذاری شوند.
۳. فایل `reservation.html` یا `signup.html` را در مرورگر باز کنید.

> برای ثبت واقعی اطلاعات، اعتبارسنجی سمت سرور و ذخیره‌سازی داده‌ها، باید صفحات در مراحل بعدی به Django متصل شوند.
